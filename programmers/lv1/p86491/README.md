## 문제 요약

여러 크기의 명함을 모두 수납할 수 있는 가장 작은 지갑의 크기를 구하는 문제이다.

각 명함은 `[가로, 세로]` 형태로 주어지지만, 명함은 회전해서 넣을 수 있다.

- **회전 가능** : `[w, h]`와 `[h, w]`는 동일하게 취급할 수 있다.
- **목표** : 모든 명함을 넣을 수 있도록 가로와 세로의 최소 크기를 정한다.
- **제한 사항** : 명함의 개수는 최대 10,000개, 각 변의 길이는 최대 1,000이다.

## 핵심 포인트

이 문제에서 가장 중요한 점은 **명함을 회전할 수 있다는 사실을 어떻게 일반화할 것인가**이다.

처음에는 각 명함의 가로 길이 중 최댓값과 세로 길이 중 최댓값을 구하는 방법을 생각할 수 있다.

예를 들어 다음과 같은 명함이 있다고 하자.

```text
[60, 50]
[30, 70]
[60, 30]
[80, 40]
```

단순히 가로와 세로의 최댓값을 각각 구하면

```text
가로 최댓값 = 80
세로 최댓값 = 70
```

이므로 지갑의 크기는

```text
80 × 70 = 5600
```

이 된다.

하지만 `[30, 70]` 명함을 회전시키면 `[70, 30]`으로 넣을 수 있으므로 실제로는 더 작은 지갑을 만들 수 있다.

### 1. 명함의 방향 통일

각 명함마다 긴 변과 짧은 변을 구한 뒤 모든 명함의 방향을 동일하게 맞춘다.

즉,

```text
긴 변  → 가로
짧은 변 → 세로
```

로 배치한다고 생각한다.

각 명함 `[w, h]`에 대해

```java
Math.max(w, h)
Math.min(w, h)
```

를 사용하면 된다.

예를 들어:

```text
[60, 50] → [60, 50]
[30, 70] → [70, 30]
[60, 30] → [60, 30]
[80, 40] → [80, 40]
```

이렇게 모든 명함을 **가로가 세로보다 길거나 같도록 통일**할 수 있다.

### 2. 지갑의 크기 결정

모든 명함의 방향을 통일했다면 지갑의 가로 길이는 각 명함의 긴 변 중 가장 큰 값이어야 한다.

```text
max(60, 70, 60, 80) = 80
```

지갑의 세로 길이는 각 명함의 짧은 변 중 가장 큰 값이어야 한다.

```text
max(50, 30, 30, 40) = 50
```

따라서 필요한 최소 지갑의 크기는

```text
80 × 50 = 4000
```

이 된다.

## 동작 원리

1. **명함 순회** : `sizes` 배열의 모든 명함을 하나씩 확인한다.
2. **방향 통일** : 각 명함의 두 변 중 큰 값을 가로, 작은 값을 세로라고 가정한다.
3. **최댓값 갱신** : 모든 명함의 긴 변 중 최댓값과 짧은 변 중 최댓값을 각각 구한다.
4. **결과 계산** : 두 최댓값을 곱하여 모든 명함을 수납할 수 있는 최소 지갑의 크기를 반환한다.

### 전체 코드

```java
class Solution {
    public int solution(int[][] sizes) {
        int width = Integer.MIN_VALUE;
        int height = Integer.MIN_VALUE;

        for (int[] size : sizes) {
            width = Math.max(width, Math.max(size[0], size[1]));
            height = Math.max(height, Math.min(size[0], size[1]));
        }

        return width * height;
    }
}
```

조금 더 단순하게 초기값을 `0`으로 설정해도 된다. 명함의 길이는 항상 1 이상이기 때문이다.

```java
class Solution {
    public int solution(int[][] sizes) {
        int width = 0;
        int height = 0;

        for (int[] size : sizes) {
            width = Math.max(width, Math.max(size[0], size[1]));
            height = Math.max(height, Math.min(size[0], size[1]));
        }

        return width * height;
    }
}
```

## 시간 복잡도

명함의 개수를 `N`이라고 할 때 모든 명함을 한 번씩만 순회한다.

각 명함에서 수행하는 `Math.max()`, `Math.min()` 연산은 모두 `O(1)`이다.

따라서 최종 시간 복잡도는

\[
O(N)
\]

이다.

추가적인 배열이나 자료구조를 사용하지 않으므로 공간 복잡도는

\[
O(1)
\]

이다.
