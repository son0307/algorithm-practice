# 프로그래머스 42895 - N으로 표현

## 문제 요약

숫자 `N`과 사칙연산만 사용하여 `number`를 표현할 때, `N`을 사용하는 횟수의 최솟값을 반환하는 문제이다.

- **사용 가능한 연산** : 덧셈, 뺄셈, 곱셈, 나눗셈과 괄호
- **이어붙이기** : `N`, `NN`, `NNN`과 같이 같은 숫자를 이어붙여 사용할 수 있음
- **나눗셈** : 정수 나눗셈을 사용하며 나머지는 무시함
- **목표** : `number`를 만들기 위해 필요한 `N`의 최소 사용 횟수를 반환
- **제한 사항** : 최소 사용 횟수가 8보다 크면 `-1`을 반환

## 핵심 포인트

이 문제는 `N`을 몇 번 사용했는지를 기준으로 만들 수 있는 숫자들을 구분하여 저장하는 것이 중요하다.

단순히 가능한 수식을 모두 직접 만들어 검사하면 같은 계산이 반복되고, 수식의 조합도 빠르게 증가한다. 따라서 이미 계산한 결과를 다시 활용할 수 있도록 DP를 사용한다.

`N`을 1개 사용한 경우부터 8개 사용한 경우까지 차례대로 계산하고, 각 단계에서 `number`가 만들어지는지 검사한다. 작은 사용 횟수부터 탐색하므로 `number`가 처음 등장한 시점의 사용 횟수가 최솟값이 된다.

1. **DP와 HashSet**

   `dp[i]`에는 `N`을 정확히 `i`개 사용하여 만들 수 있는 모든 정수를 저장한다.

   ```text
   dp[i] = N을 정확히 i개 사용하여 만들 수 있는 숫자들의 집합
   ```

   같은 숫자가 여러 수식에서 중복으로 만들어질 수 있으므로 `HashSet`을 사용한다. 이를 통해 중복된 결과를 한 번만 저장하고, 이후 연산에서도 같은 값을 반복해서 사용하는 경우를 줄일 수 있다.

2. **이어붙인 수 처리**

   사칙연산으로 만든 결과뿐만 아니라 `55`, `555`와 같이 `N`을 이어붙인 수도 고려해야 한다.

   이어붙인 수는 다음 식을 반복하여 만들 수 있다.

   ```java
   temp = temp * 10 + N;
   ```

   예를 들어 `N = 5`일 때 `i = 3`이라면 다음과 같이 계산된다.

   ```text
   0 -> 5 -> 55 -> 555
   ```

   이렇게 만든 값은 `N`을 정확히 `i`개 사용하므로 `dp[i]`에 추가한다.

3. **모든 분할 `j`와 `i - j` 조합**

   `N`을 `i`개 사용하여 만들 수 있는 값은, `N`을 `j`개 사용한 결과와 `i - j`개 사용한 결과를 사칙연산하여 만들 수 있다.

   따라서 `j`를 1부터 `i - 1`까지 순회하며 `dp[j]`와 `dp[i - j]`의 모든 원소 조합에 사칙연산을 적용한다.

   예를 들어 `N`을 4개 사용하는 경우에는 다음 분할을 모두 확인한다.

   ```text
   dp[1]과 dp[3]
   dp[2]와 dp[2]
   dp[3]과 dp[1]
   ```

   뺄셈과 나눗셈은 피연산자의 순서에 따라 결과가 달라진다. 하지만 `(1, i - 1)`부터 `(i - 1, 1)`까지 모든 분할을 순회하므로 반대 순서의 연산도 다른 분할에서 자연스럽게 처리된다. 따라서 하나의 원소 조합에서는 `i1 - i2`, `i1 / i2`만 계산해도 충분하다.

   단, 나눗셈을 수행할 때는 0으로 나눌 수 없으므로 `i2`가 0이 아닌 경우에만 결과를 추가한다.

### 동작 원리

1. **초기값 처리** : `number`가 `N`과 같으면 `N`을 한 번만 사용하면 되므로 1을 반환한다.
2. **DP 배열 생성** : `dp[i]`에 `N`을 정확히 `i`개 사용하여 만들 수 있는 숫자들을 저장한다.
3. **이어붙인 수 추가** : 각 `i`에 대해 `NN...N` 형태의 수를 만들고 `dp[i]`에 추가한다.
4. **분할 조합 계산** : 모든 `j`에 대해 `dp[j]`와 `dp[i - j]`의 원소들을 사칙연산하고 그 결과를 `dp[i]`에 저장한다.
5. **목표값 확인** : 현재 집합에 `number`가 포함되어 있으면 `i`를 반환한다.
6. **실패 처리** : `N`을 8개 사용한 경우까지 `number`를 만들지 못하면 `-1`을 반환한다.

### 전체 코드

```java
package programmers.lv3.p42895;

import java.util.*;

public class p42895 {

    public int solution(int N, int number) {
        HashSet<Integer>[] dp = new HashSet[9];

        // N 1개로 해결되는 경우
        if(number == N) return 1;
        dp[1] = new HashSet<>();
        dp[1].add(N);

        // N을 2개 이상 사용해야 하는 경우
        for(int i = 2; i < 9; i++) {
            dp[i] = new HashSet<>();

            // 'NN'과 같은 경우 검사
            int temp = 0;
            for(int j = 0; j < i; j++) {
                temp = temp * 10 + N;
            }
            if (temp == number) return i;
            dp[i].add(temp);

            // j개를 사용하는 경우, i - j개를 사용하는 경우를 가져와서 사칙연산
            for(int j = 1; j < i; j++) {
                HashSet<Integer> s1 = dp[j];
                HashSet<Integer> s2 = dp[i - j];

                for(int i1 : s1) {
                    for (int i2 : s2) {
                        dp[i].add(i1 + i2);
                        dp[i].add(i1 - i2);
                        dp[i].add(i1 * i2);

                        if(i2 != 0) {
                            dp[i].add(i1 / i2);
                        }
                    }
                }

                if(dp[i].contains(number)) return i;
            }
        }

        return -1;
    }

    public static void main(String[] args) {
        p42895 p = new p42895();
        int N1 = 5;
        int number1 = 5;
        int N2 = 2;
        int number2 = 11;
        System.out.println(p.solution(N1, number1));
        System.out.println(p.solution(N2, number2));
    }
}
```

## 시간복잡도

`dp[i]`에 저장된 원소의 개수를 `S_i`라고 할 때, `dp[i]`를 만들기 위해 모든 분할의 두 집합을 조합하므로 필요한 연산 횟수는 다음과 같다.

$$
O\left(\sum_{i=2}^{8}\sum_{j=1}^{i-1} S_j \times S_{i-j}\right)
$$

각 원소 조합에서는 최대 네 번의 사칙연산과 `HashSet` 삽입을 수행한다. 문제에서 `N`의 사용 횟수를 최대 8개로 제한하고 있고, `HashSet`이 중복된 결과를 제거하므로 주어진 범위 안에서 충분히 처리할 수 있다.

공간복잡도는 각 단계에서 만들어진 결과를 모두 저장하므로 다음과 같다.

$$
O\left(\sum_{i=1}^{8} S_i\right)
$$
