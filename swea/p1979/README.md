### 1. 문제 요약
   N × N 퍼즐에서 흰색 칸은 1, 검은색 칸은 0으로 주어진다. 가로와 세로에서 흰색 칸이 정확히 K개 연속된 자리의 수를 구해야 한다.

예를 들어 K = 3일 때 0 1 1 1 0에는 단어가 들어갈 자리 한 곳이 있다. 반면 0 1 1 1 1 0은 흰색 칸이 4개 이어져 있으므로 길이 3인 자리로 세지 않는다.
### 2. 핵심 포인트
   흰색 칸을 만날 때마다 개수를 세고, 그 구간이 끝났을 때 길이가 K인지 확인한다.

여기서 주의할 점은 줄의 마지막 칸까지 흰색이 이어지는 경우다. 예를 들어 0 0 1 1 1은 마지막에 검은 칸이 없어서, 검은 칸을 만났을 때만 검사하면 이 자리를 놓친다.

이를 해결하기 위해 배열을 (n + 1) × (n + 1)로 만든다. 실제 퍼즐은 앞의 n × n 영역에만 저장하고, 추가된 마지막 행과 열은 int 배열의 기본값인 0으로 둔다. 이 0들이 각 줄을 끝내는 검은 칸 역할을 한다.
### 3. 동작 원리
   i번째 행과 i번째 열을 동시에 살펴본다.
- map[i][j]는 가로 방향의 칸이다. 흰색이면 hor를 늘린다.
- map[j][i]는 세로 방향의 칸이다. 흰색이면 ver를 늘린다.
- 검은 칸을 만나면 그 방향에서 이어져 온 흰색 칸의 개수가 k인지 확인한다. 같으면 ans를 1 늘리고, 개수를 0으로 초기화한다.
  예를 들어 K = 3이고 한 행이 0 1 1 1 0이라면, 가운데 세 칸을 지나는 동안 hor가 1 → 2 → 3이 된다. 다음 0을 만났을 때 hor == k이므로 정답에 1을 더한다.

한 행이 0 0 1 1 1처럼 끝난다면 j == n일 때 추가해 둔 마지막 열의 0을 만난다. 따라서 이 경우에도 hor == k를 검사할 수 있다. 세로 방향도 마지막 행의 0으로 같은 방식으로 처리한다.
### 4. 전체 코드 
    import java.util.*;
    
    public class Solution {
    public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    
            int T = sc.nextInt();
    
            for (int tc = 1; tc <= T; tc++) {
                int n = sc.nextInt();
                int k = sc.nextInt();
    
                // 마지막 행과 열은 기본값 0으로 남겨 둔다.
                int[][] map = new int[n + 1][n + 1];
    
                // 실제 퍼즐은 n × n 영역에만 저장한다.
                for (int i = 0; i < n; i++) {
                    for (int j = 0; j < n; j++) {
                        map[i][j] = sc.nextInt();
                    }
                }
    
                int ans = 0;
    
                for (int i = 0; i < n; i++) {
                    int hor = 0; // i번째 행에서 연속된 흰색 칸의 수
                    int ver = 0; // i번째 열에서 연속된 흰색 칸의 수
    
                    // j == n일 때 추가된 검은 칸까지 확인한다.
                    for (int j = 0; j <= n; j++) {
                        if (map[i][j] == 1) {
                            hor++;
                        } else {
                            if (hor == k) ans++;
                            hor = 0;
                        }
    
                        if (map[j][i] == 1) {
                            ver++;
                        } else {
                            if (ver == k) ans++;
                            ver = 0;
                        }
                    }
                }
    
                System.out.println("#" + tc + " " + ans);
            }
        }
    }

i번째 행과 i번째 열은 방향이 다른 자리로 각각 계산한다. 같은 흰색 칸을 지나더라도 가로 자리 하나와 세로 자리 하나라면 각각 세는 것이 맞다.
### 5. 시간 복잡도
   테스트 케이스마다 N × N칸을 입력받고, 모든 행과 열을 확인한다. 따라서 **시간 복잡도는 \(O(N^2)\)** 이다.

배열 크기는 (N + 1) × (N + 1)이므로 **공간 복잡도는 \(O(N^2)\)** 이다.
