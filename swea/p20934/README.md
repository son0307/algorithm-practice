### 1. 문제 요약
   처음 방울이 들어 있던 컵의 위치와 방울이 울린 횟수 \(K\)가 주어진다. 이를 바탕으로 현재 방울이 있을 확률이 가장 높은 위치를 구한다. 확률이 같은 위치가 여러 개라면 가장 왼쪽 위치를 선택한다.
### 2. 핵심 포인트
   방울은 방울이 들어 있는 컵이 교환될 때만 울린다. 따라서 방울이 한 번 울릴 때마다 위치는 가장자리와 가운데 사이에서 바뀐다.

방울이 울리지 않은 교환은 방울의 위치에 영향을 주지 않으므로, 위치를 판단할 때는 전체 교환 횟수가 아닌 \(K\)의 홀짝을 확인하면 된다.
### 3. 동작 원리
   처음 위치가 가장자리인 경우, \(K\)가 홀수이면 방울은 가운데에 있다. \(K=0\)이면 처음 위치에 그대로 있다. 양의 짝수이면 양쪽 가장자리가 가능한 위치이며, 확률이 같으므로 왼쪽 위치인 0을 선택한다.

처음 위치가 가운데인 경우, \(K\)가 짝수이면 가운데에 있다. 홀수이면 양쪽 가장자리의 확률이 같으므로 왼쪽 위치인 0을 선택한다.
### 4. 전체 코드
    import java.util.*;
    
    public class Solution {
        public static void main(String[] args) {
            Scanner sc = new Scanner(System.in);
    
            int T = sc.nextInt();
            for (int tc = 1; tc <= T; tc++) {
                String s = sc.next();
                int k = sc.nextInt();
                int ans = 0;
    
                if (s.equals("o..") || s.equals("..o")) {
                    if (k == 0) {
                        ans = s.indexOf('o');
                    } else if (k % 2 == 1) {
                        ans = 1;
                    }
                } else {
                    if (k % 2 == 0) {
                        ans = 1;
                    }
                }
    
                System.out.println("#" + tc + " " + ans);
            }
        }
    }

### 5. 시간 복잡도
   각 테스트 케이스에서 처음 위치와 \(K\)의 홀짝만 확인한다. 따라서 **시간 복잡도는 \(O(1)\)** 이고, 추가 공간 복잡도도 **\(O(1)\)** 이다.
